TallyVeda demo data - for test computers only
=============================================

This zip fills empty Tally companies with made-up books, so TallyVeda can be
tested end to end on a computer whose Tally has no real data. There are five
programs, one per demo company. Each one fills only the company with its own
name, and only when that company is empty. It never touches any other company.

Never run these on a computer that keeps a business's real books in Tally.


Before you start
----------------
1. TallyPrime is open on this computer.
2. Tally's data connection is on: F1 (Help) > Settings > Connectivity, set
   "TallyPrime acts as" to Server or Both, and the port to 9000.
3. Licensed Tally only: Tally's Educational Mode accepts entries dated only on
   the 1st, 2nd and 31st of a month, so most of the demo books would not go in.

Loading one company
-------------------
1. Create the company as above and keep it open in Tally.
2. Double-click its program (for example TallyVedaDemo-Healthy.exe). If
   Windows shows "Windows protected your PC", click More info > Run anyway.
3. Wait until it says "Done" (a few minutes; 9,000 to 12,000 entries). Keep
   Tally open meanwhile. If it stops, run it again: it carries on where it
   stopped.
4. Share the company with TallyVeda as usual, using a new access code for it.

Load the companies one at a time. Tally can only take one import at once.


If something goes wrong
-----------------------
"No company named ... is open in Tally"
    The company isn't created, isn't open, or its name differs. The name must
    match exactly, including spaces.
"keeps books from ..., but the demo books start on ..."
    Create the company again with both dates as listed above.
"already has vouchers that this program did not create"
    That company already has other entries, so nothing was written. Create a
    new, empty company with the listed name.
"Tally is not answering"
    Check the connectivity setting under "Before you start".
Tally reports rejected entries at the end
    Send a photo of the program's window to the TallyVeda team.
